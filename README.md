- C++17 o superior

## 🔧 Instalación y Compilación

### Con CLion:
1. Clonar repositorio
2. Abrir con CLion
3. CLion detectará automáticamente el CMakeLists.txt
4. Click en "Build"

### Con terminal:
```bash
mkdir build
cd build
cmake ..
make
